# 🚗 Vehicle Detection Using Pretrained Detectors
## Faster R-CNN vs YOLO

### MCA 3rd Semester | AI & Machine Learning Project

## 📌 Project Overview

This project focuses on vehicle detection using two pretrained deep learning models:

1. YOLO (You Only Look Once)
2. Faster R-CNN (Region-based Convolutional Neural Network)

The main objective is to detect vehicles in images and videos and compare the performance of both models.

## 🎯 Project Objectives

- Detect cars, buses, trucks and motorcycles.
- Implement pretrained YOLO model.
- Implement Faster R-CNN model.
- Compare detection accuracy and speed.
- Analyze model performance using graphs.
